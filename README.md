# Script — démo web

Un logiciel pour ceux qui font des films : gestion du scénario jusqu'au budget, en passant par le storyboard, le découpage et le planning.

Ceci est une **démo dans le navigateur** de l'application Script — build web auto-généré, publié ici pour essayer l'app sans rien installer. Le code source vit dans un dépôt privé ; ce dépôt-ci ne contient que le résultat compilé (JavaScript et CSS minifiés), pas de code source ni de sourcemaps.

👉 **[Essayer la démo](https://phoenix-k-dev.github.io/Script-review/)**

## Ce qui fonctionne

Créer un projet, écrire un scénario au format Fountain (autocomplétion, verrouillage de la numérotation des scènes, export PDF), ajouter des panneaux de storyboard, gérer le découpage, le planning et le budget — les mêmes fonctionnalités que l'application installée.

**Limite importante** : dans cette démo, les projets sont stockés dans le navigateur lui-même (IndexedDB), pas dans un vrai fichier. Vider le cache ou les données du site les efface définitivement. C'est fait pour essayer l'app, pas pour y garder du vrai travail.

## Pour du vrai travail : l'application installée

L'application desktop (Windows/macOS/Linux) stocke les projets comme de vrais dossiers sur le disque, avec accès complet au système de fichiers. Téléchargements disponibles dans l'onglet **[Releases](https://github.com/Phoenix-k-dev/Script-review/releases)** de ce dépôt.

## Support

Script est gratuit. Un bouton de soutien libre (don ponctuel via Stripe) est disponible dans l'application, sans obligation et sans débloquer de fonctionnalité.
